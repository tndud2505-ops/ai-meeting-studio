# 회의

Codex, Claude, Gemini와 사용자가 함께 대화하는 Windows 로컬 회의 앱입니다.
프로필과 말풍선이 있는 흰색 대화방, 설치 가능한 PWA로 구성되어 있습니다.

## 실행

다른 PC에서 처음 실행하는 방법:

1. GitHub 비공개 저장소에 접근할 수 있는 계정으로 클론합니다.
2. Node.js 22 이상을 설치합니다. 회의 서버는 별도 npm 패키지 설치 없이 실행됩니다.
3. 사용할 공식 CLI를 설치합니다. Codex: OpenAI Codex CLI 설치 안내, Claude: Claude Code 설치 안내, Gemini: Google Antigravity CLI 설치 안내를 아래에서 참고합니다.
4. 클론한 폴더의 START_STUDIO.cmd를 실행합니다. 또는 OPEN_MEETING.vbs를 실행하여 별도 앱 창으로 엽니다.
5. 상단 AI 프로필의 연결 탭에서 로그인하고 응답 테스트를 실행합니다. 이전 PC의 로그인 정보는 복제하지 않습니다.

공식 설치: [Codex CLI](https://developers.openai.com/codex/cli/) · [Claude Code](https://code.claude.com/docs/en/overview) · [Antigravity CLI](https://antigravity.google/docs/cli/).

- 바탕화면 **회의** 바로가기를 실행합니다. 로컬 서버가 꺼져 있으면 먼저 켠 뒤 앱 창을 엽니다.
- 폴더에서 직접 실행하려면 `OPEN_MEETING.vbs`를 더블클릭합니다.
- 일반 브라우저: <http://127.0.0.1:4317/>
- 브라우저가 제공하는 **앱 설치** 버튼으로 PWA를 설치할 수 있습니다. 설치 완료 후에는 브라우저의 앱 목록에도 표시됩니다.
- 서버는 현재 사용자 Windows 로그인 시 자동 시작합니다. 앱 화면을 자동으로 열지는 않습니다.
- 서버를 종료하려면 `STOP_STUDIO.cmd`를 실행합니다.

바탕화면 바로가기는 서버 시작까지 처리하는 앱 창 실행기입니다. 브라우저의 PWA 등록 여부와는 별개이며, PWA 등록은 브라우저 설치 확인으로 완료됩니다.

## 대화

1. 상단에서 각 모델을 고릅니다.
2. 메시지를 입력하고 Enter 또는 전송 버튼을 누릅니다.
3. 선택한 AI가 진행 설정에 따라 순차 대화하거나 동시 조사 후 상호 검토합니다.
4. 다음 메시지를 보내면 이어서 답합니다. 사용자 메시지 없이 AI 대화를 더 이어가려면 **계속**을 누릅니다.
5. 생성 중에는 **일시정지**로 이미 시작한 발언들이 끝난 뒤 멈출 수 있습니다.
6. **초기화**는 진행 중인 요청을 중지하고 새 문맥을 시작합니다. 기존 대화 파일은 로컬 기록 폴더에 남습니다.

처음부터 **시작**을 누르면 입력창에서 첫 메시지를 기다립니다. 실행 중에 보낸 사용자 메시지는 다음 발언부터 반영됩니다. AI 호출은 사용자 메시지나 시작/계속 동작에 따라 제한된 차례로 진행하며 무한 반복하지 않습니다.

## 진행 및 도구 설정

입력창 옆 톱니바퀴 버튼에서 진행 방식과 도구를 설정합니다.

| 진행 방식 | 동작 |
|---|---|
| 자동 선택 | 일반 회의는 순차 대화, 조사·검색·시장 비교 요청은 동시 조사 후 검토로 선택합니다. 판단은 사용자 메시지의 키워드에 기반하며 직접 선택할 수도 있습니다. 순차 자동 모드에서는 첫 발언자가 회차마다 바뀝니다. |
| 순차 대화 | 한 AI의 답변이 완료되면 그 내용을 다음 AI에게 전달합니다. |
| 동시 조사 후 토론 | 선택한 AI들이 동일한 초기 대화 기록으로 각자 조사합니다. 먼저 완료한 답변부터 표시하고 모두 끝난 후 완료 순서로 상호 검토합니다. 마지막 검토자가 후보, 근거, 우선순위 및 남은 불확실성을 정리합니다. |

특정 AI에게 질문하려면 @Codex, @Claude, @Gemini 또는 @표시이름을 메시지에 넣습니다. 해당 AI가 참가 설정에 켜져 있어야 합니다. 새 메시지의 지목만 적용되고, 그 다음 계속 버튼에서는 일반 그룹 회의로 돌아갑니다.

| 도구 권한 | 동작 |
|---|---|
| 대화만 | 외부 도구를 사용하지 않고 대화합니다. |
| 웹 검색 및 자료 조사 (기본) | 공식 CLI 웹 도구를 활성화합니다. PC 파일·터미널 작업은 제한합니다. 답변에 포함된 HTTP(S) 출처 링크는 클릭할 수 있습니다. |
| 프로젝트 파일 · 터미널 · 웹 | 신뢰할 수 있는 실제 프로젝트 폴더의 절대 경로를 지정하고 확인합니다. 선택된 AI가 해당 폴더에서 공식 CLI의 파일 읽기·편집, 터미널, 웹 도구를 사용합니다. 동시 파일 수정 충돌을 피하기 위해 항상 순차 실행합니다. |

예를 들어 자동/웹 모드에서 "플레이스토어의 수익성 높은 앱 분야를 조사해서 토론해줘"라고 입력하면 독립 조사와 상호 검토가 진행됩니다. 프로젝트 작업 모드에서 폴더를 지정하고 "현재 코드를 검토하고 개선해줘"라고 입력하면 실제 파일을 검토·수정할 수 있습니다.

프로젝트 작업은 공식 CLI의 샌드박스와 권한 규칙을 적용합니다. 모든 PC 파일에 무제한 접근하거나 승인 요구를 우회하지 않습니다. CLI가 추가 확인을 요구하거나 도구를 지원하지 않는 작업은 실패할 수 있습니다. 특히 Windows의 Antigravity 터미널 샌드박스가 특정 폴더에서 쓰기를 제한할 수 있습니다. 이 경우 파일 편집 도구를 먼저 사용하도록 안내합니다. Claude Code는 추가 승인이 필요한 명령을 비대화형 세션에서 거부할 수 있습니다.

조사 도중 새 답변을 실행 중인 다른 CLI 요청의 입력으로 주입하지 않습니다. 조사 단계가 끝나면 완료한 응답들과 사용자의 추가 메시지를 상호 검토에 전달합니다. 일부 응답 실패 시 성공한 조사를 유지하고 계속 버튼으로 실패한 차례를 재시도합니다. 출력 기록에는 확인된 CLI 도구 이벤트의 종류만 남기고 도구 인자나 비공개 추론 로그는 기록하지 않습니다.

## 프로필, 역할, 추론 강도

상단 모델의 프로필을 누르면 이름, 사진 또는 아이콘, 색상, 참가 여부, 모델과 추론 강도를 편집할 수 있습니다. 입력창 왼쪽의 내 프로필도 바꿀 수 있습니다. 프로필은 이 PC에 저장되어 다른 앱 창에서도 동일하게 적용됩니다.

**역할** 탭에서 각 AI가 대화에 참여할 방식을 Markdown으로 편집합니다. 이름과 역할의 변경은 다음 발언부터 적용되며 이전 발언의 이름은 당시 기록을 유지합니다. 화면에서는 AI 말풍선이 왼쪽, 내 말풍선이 오른쪽에 표시됩니다.

| 모델 | 역할 파일 | 기본 역할 |
|---|---|---|
| Codex | `studio/roles/codex.md` | 아이디어를 규칙과 실행안으로 구체화 |
| Claude | `studio/roles/claude.md` | 전제·사용자 경험·제약 검토 |
| Gemini | `studio/roles/gemini.md` | 다른 관점과 새로운 조합 제안 |

역할 편집기의 **저장**은 해당 Markdown 파일을 UTF-8로 저장합니다. 파일을 직접 편집해도 됩니다. 서버는 각 발언 직전에 파일을 다시 읽습니다. 역할 파일명과 해시는 발언 기록에 남아 사용한 설정을 확인할 수 있습니다.

추론 강도는 제공자와 모델에서 확인된 값만 선택 목록에 표시합니다. 높은 강도는 시간이 더 걸릴 수 있습니다. 화면에는 모델이 반환한 공개 발언만 표시됩니다.

## 연결

- Codex: 설치된 공식 Codex CLI와 ChatGPT 로그인을 사용합니다.
- Claude: 설치된 공식 Claude Code와 Claude 로그인을 사용합니다. 설정의 **로그인** 버튼은 공식 로그인 터미널을 엽니다.
- Gemini: 공식 Antigravity CLI와 Google 로그인을 사용합니다. 개인용 Gemini CLI의 기존 경로 대신 현재 공식 경로를 사용합니다.
- **연결** 탭의 **응답 테스트**는 선택한 모델과 추론 강도로 짧은 실제 요청을 한 번 실행합니다.
- 테스트마다 새 확인 코드를 보내고 실제 답변에서 같은 코드가 돌아왔는지 검사합니다. 답변, 확인 시각, 실행 시간, 모델, CLI 버전이 기록됩니다.
- 로그인 상태와 마지막 응답 테스트 결과는 별도로 표시합니다. 과거에 성공했더라도 현재 로그인이 풀려 있으면 다시 로그인해야 합니다.
- 모델 이름은 CLI가 직접 보고한 값인지, 요청 시 지정한 값인지 구분합니다. CLI가 정확한 모델 이름을 반환하지 않는 경우 확인된 것처럼 표시하지 않습니다.
- 앱이 계정 토큰이나 비밀번호를 입력받거나 저장하지 않습니다. 공식 CLI가 인증을 관리합니다.
- 계정별 사용 한도와 모델 이용 가능 범위가 적용됩니다. 로그인 상태와 실제 응답 성공은 구분해서 처리합니다.

2026-11-25 한국 시간 기준, HOME PC에서 Codex와 Gemini의 실제 응답, 웹 도구 사용, 프로젝트 파일 작업을 검증했습니다. Codex의 터미널 파일 복사도 검증했습니다. Gemini 터미널의 일부 파일 쓰기는 Windows 권한 오류가 발생했지만 기본 파일 편집 도구로 성공했습니다. Claude Code는 설치되어 있으나 구독 계정 로그인은 아직 완료되지 않아 실제 호출 검증이 남아 있습니다.

## 저장 및 오프라인

- 대화: `studio/data/rooms/*.json`
- 역할: `studio/roles/*.md`
- 프로필: `studio/data/profiles.json`
- 실제 연결 확인 기록: `studio/data/provider-checks.json`
- 서버 로그: `studio/data/server.log`, `studio/data/server-error.log`
- 새 대화방 디자인 참고 이미지: `design/chatroom-reference-v2.png`

PWA는 화면 파일만 캐시합니다. API 응답, 대화 내용, 프로필, 인증 확인 기록, 역할 파일은 서비스 워커 캐시에 넣지 않습니다. 실제 AI 대화에는 실행 중인 로컬 서버와 인터넷 연결이 필요합니다. 업데이트는 진행 중인 회의를 자동으로 새로고침하지 않습니다.

서버 자동 시작을 해제하려면 Windows의 현재 사용자 시작프로그램 폴더에서 `AI-Meeting-Studio-Server.lnk` 하나를 제거하면 됩니다. 프로젝트나 다른 시작프로그램을 지울 필요는 없습니다.

## 개발 및 확인

Node.js 22 이상을 권장하며 추가 런타임 패키지 설치 없이 실행됩니다.

```powershell
npm run studio
npm run test:studio
```

서버는 `127.0.0.1:4317`에만 바인딩하며, 같은 출처의 JSON 요청만 변경 작업에 허용합니다. 대화/조사 모드에서는 AI별 전용 작업 폴더를 사용하고 프로젝트 모드에서는 사용자가 선택한 폴더에서 공식 CLI 권한으로 실행합니다. 중지 시 해당 요청의 자식 프로세스를 함께 종료합니다. 로그인 정보, 개인 프로필, 대화, 테스트 임시 폴더는 Git에 포함하지 않습니다.
